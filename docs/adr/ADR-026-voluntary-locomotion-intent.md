# ADR-026: 自発移動意図は物理速度ではなく主体が開始しようとする方向を表す

- Status: Accepted
- Date: 2026-08-20

## Context

- 自発移動制御判断は存在するが、制御対象となる意味的な移動意図がなかった。
- 現行入力は直接位置変更へ接続されている互換経路である。
- 物理速度を意図として使うと、主体の意思と物理結果が混ざる。
- Inputと将来のAI判断が共通して出力できる意味型が必要である。

## Decision

- privateな `自発移動意図` を追加する。
- 意図ID、発行Tick、実行者ID、四方向、由来を保持する。
- 方向は物理速度、変位、移動距離ではない。
- 明示方向と既存Input由来の二つの生成経路を提供する。
- 左右上下の移動入力を網羅的に変換する。
- ジャンプ、攻撃、入力なしは正常な意図なしとし、意図用ID、Tick、実行者IDを検証しない。
- 上下入力は現行Movementが未対応でも意味的な意図として生成する。
- 意図はWorld Truth、Event、因果操作、正式履歴ではない。

## Consequences

- Inputと将来AIの移動判断を共通境界へ接続できる。
- 物理Movementから独立して意図を検証・抑制できる。
- 非移動入力をダミー意図へ変換しない。
- 斜め、強度、目的位置、経路、AI専用由来は後続となる。
- 既存Movementはまだ意図を使用しない。

## Implementation Status

意図の主体・Tickを保持する互換命令の適用前検証をADR-029で追加した。意図を再発行・補正せず、現在GameStateへ照合する独立境界である。意図や旧Movementの契約は変更しない。

実装済み:

- privateな `自発移動意図`
- 明示ID、Tick、実行者ID、左・右・上・下、由来のアクセサ
- 明示方向からの純粋生成
- 既存Input全caseの網羅的な純粋変換
- 非移動入力と入力契約エラーの分離

未実装:

- 斜め、任意ベクトル、意図強度、目的位置、経路
- AI専用由来、意図予約、期限、持越し
- 互換命令のMovement適用AdapterとWorld Truthへの適用（Gate後の純粋な互換変換はADR-028で実装済み）
