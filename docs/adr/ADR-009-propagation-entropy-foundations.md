# ADR-009: 物理情報伝播層とエントロピー基盤を導入

- Status: Accepted
- Date: 2026-07-10

## Context

AIの非全知性を成立させるには、火、煙、匂い、振動、権能残滓などが世界からセンサーへ届く共通経路が必要である。
また、熱、物質、構造、痕跡、情報、常態維持負荷は同じ「劣化値」では扱えない。

## Decision

風土Propagationとして、発生源、放出、媒体、伝播、減衰・拡散・反射・混合、感知値までの物理情報伝播層を導入する。

黄泉Entropyとして、熱散逸、物質拡散、構造劣化、痕跡風化、情報不確実性、常態維持負荷を分離した散逸基盤を導入する。

禍津は離散的な異常Event、黄泉Entropyは継続的な散逸、直毘Homeostasisは資源を使う秩序維持として分担する。

権能もこの伝播・散逸・観測経路を迂回しない。

## Consequences

- 伝播量、媒体、方式、散逸種別を個別に定義する。
- 権威信号とGPU表現を分離する。
- Phase 1として、伝播信号から感知値への線形距離減衰による最小変換を実装する。
- 完全な伝播演算と散逸の時間発展は後続Phaseとする。

## Implementation Status

実装済み:

- 伝播信号、感知値、散逸状態の契約型
- 正式因果IDと実行者IDを由来として固定する地盤振動信号生成
- 発生位置との直線距離、線形減衰、感度、閾値、確信度飽和による感知値生成
- 正常な非感知と不正入力の分離

未実装:

- 信号自体の移動、移流、拡散、伝導、波動
- 媒体場、遮蔽、反射、混合
- 複数信号の合成と意味保存LOD
- 散逸状態の時間発展と直毘Operation

Acceptedは、物理情報伝播層とエントロピー基盤を段階導入する設計判断の採択を表し、全機能の完成を意味しない。
