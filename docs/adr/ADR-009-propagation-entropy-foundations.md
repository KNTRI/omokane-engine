# ADR-009: 物理情報伝播層とエントロピー基盤を導入

- Status: Proposed
- Date: 2026-07-10

## Context

AIの非全知性を成立させるには、火、煙、匂い、振動、権能残滓などが世界からセンサーへ届く共通経路が必要である。
また、熱、物質、構造、痕跡、情報、常態維持負荷は同じ「劣化値」では扱えない。

## Decision

風土Propagationとして、発生源、放出、媒体、伝播、減衰・拡散・反射・混合、感知値までの物理情報伝播層を導入する。

黄泉Entropyとして、熱散逸、物質拡散、構造劣化、痕跡風化、情報不確実性、常態維持負荷を分離した散逸基盤を導入する。

禍津は離散的な異常Event、黄泉Entropyは継続的な散逸、直毘Homeostasisは資源を使う秩序維持として分担する。

権能もこの伝播・散逸・観測経路を迂回しない。

## Consequences

- 伝播量、媒体、方式、散逸種別を個別に定義する。
- 権威信号とGPU表現を分離する。
- 今回は契約型と検証だけを追加し、伝播・散逸計算は実装しない。
