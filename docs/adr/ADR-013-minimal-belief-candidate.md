# ADR-013: 観測からの最小信念候補生成は明示的な根拠・反証と軟証拠集約を使う

- Status: Accepted
- Date: 2026-07-28

## Context

`信念候補` 型は存在するが、観測から生成する処理がなかった。
観測の概要を自然言語解析して根拠・反証へ自動分類すると、分類理由が暗黙になり、Phase 1としては責務が大きすぎる。
完全なベイズ推論、推論グラフ、既存信念との統合も現段階では過剰である。

## Decision

- 仮説、事前確率、根拠観測一覧、反証観測一覧を明示入力する。
- 根拠と反証の分類は呼び出し側の責務とし、概要文字列を解析しない。
- 全観測は同一観測者に属することを要求する。
- 同じ観測者であれば、異なるTickや感知種別の観測を統合可能とする。
- 事前確率を強さ1.0の事前情報とし、観測確信度を軟証拠量として集約する。
- 根拠・反証の入力順と重複をそのまま保存する。
- 算出値を完全なベイズ事後確率とは呼ばない。

## Probability Formula

```text
根拠総量 = 根拠観測の確信度の合計
反証総量 = 反証観測の確信度の合計

確率 =
  (事前確率 + 根拠総量)
  / (1.0 + 根拠総量 + 反証総量)
```

## Consequences

- 感知値から信念候補までの最小認識経路が成立する。
- 根拠と反証を説明可能な観測一覧として保持できる。
- 同一観測は入力された回数だけ証拠量へ含まれる。
- 重複判定、時間減衰、信念統合、採択、忘却は後続Phaseとなる。

## Implementation Status

実装済み:

- 明示的な仮説、事前確率、根拠観測、反証観測
- 同一観測者の検証
- 決定論的な軟証拠集約
- 入力順を維持する `信念候補` への純粋変換

未実装:

- 信念候補の採択・棄却
- 既存信念との統合
- 観測の時間減衰と忘却
- 推論グラフと矛盾解消
- 永続的な信念状態
- 信念に基づくAI判断と警戒意図
