# ADR-018: 因果起点から行動候補までの閉ループは既存の純粋境界を合成する

- Status: Accepted
- Date: 2026-08-09

## Context

地盤振動信号から感知値、観測、信念候補、警戒意図、その場警戒行動候補へ至る純粋な後段経路は存在する。
しかし、信号の原因を正式な因果操作へ接続する前段がなく、因果から認識と判断候補までの由来鎖を一本の契約で検証できなかった。
既存の距離減衰、確率集約、警戒閾値、行動候補生成を統合層へ複製すると、仕様の分岐と回帰を招く。

## Decision

次の既存境界だけを固定順で合成する。

```text
地盤振動発生実行
→ 地盤振動警戒経路
→ 行動候補生成
```

- 発生実行器が返した正式信号を再構築せず認識経路へ渡す。
- 警戒経路が返した正式な警戒意図を再構築せず行動候補生成へ渡す。
- 距離、確信度、信念確率、警戒閾値、優先度の計算を統合層へ複製しない。
- 非感知、警戒不成立、行動候補成立を異なる正常結果として返す。
- 発生、認識、行動候補のエラーへ段階名を付ける。
- World Truth変更は因果発生以外へ許可せず、その因果発生もPhase 1では状態不変とする。
- 行動候補で終了し、候補選択、行動実行、因果操作生成を行わない。

## Consequences

- 因果操作から主体固有の認識と行動候補までの由来鎖を決定論的に検証できる。
- AIはゲーム状態やWorld Truthを直接読まず、伝播信号から認識を得る。
- Eventは発生因果操作が明示した一覧だけとなり、認識段階はEventを追加しない。
- 行動候補の選択とNPC状態反映は独立した後続処理となる。
- 地盤振動生成記録の正式保存とReplayは異種因果台帳の後続設計となる。

## Implementation Status

実装済み:

- 正式因果から地盤振動信号、認識、信念、警戒意図、行動候補までの純粋合成
- 非感知、警戒不成立、行動候補成立の中間結果保持
- 因果ID、発生源、信号ID、観測者、仮説、確率のProvenance検証
- 決定論Matrixを含む正式禊Test

未実装:

- 複数観測者と複数信号
- 行動候補の選択、評価、実行
- NPC状態反映と新しい因果操作生成
- 異種因果台帳、保存、Replay
