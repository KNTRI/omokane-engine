# ADR-015: 地盤振動の技術垂直スライスは既存の純粋認識変換を順次合成する

- Status: Accepted
- Date: 2026-08-01

## Context

伝播信号から感知値、観測、信念候補、警戒意図への各変換は個別に存在するが、標準認識経路全体の接続を保証するAPIがなかった。
個別関数だけでは中間値の受け渡しと、非感知・警戒不成立・警戒成立の境界を一つの契約として検証できない。
一方、行動選択や世界状態更新まで広げるのは現段階では過剰である。

## Decision

- 1件の地盤振動信号、1人の観測者、1件の観測、1件の信念候補、1件の警戒判定に限定する。
- 既存の感知値生成、観測生成、信念候補生成、警戒意図生成を固定順で合成する。
- 距離減衰、確率集約、閾値判定を垂直スライス内へ複製しない。
- 地盤振動専用の感知種別、量種別、媒体の配線を入力契約として検証する。
- 非感知、警戒不成立、警戒成立を異なる結果として返す。
- 警戒意図を返すところで終了し、行動、因果操作、世界状態を生成しない。

## Consequences

- 標準認識経路をゲーム状態に依存しない一つの純粋関数で再現できる。
- 中間結果を検査し、非感知と警戒不成立を区別できる。
- 地盤振動以外の量種別には流用しない専用経路となる。
- NPC行動、状態変更、因果記録は後続Phaseとなる。

## Implementation Status

実装済み:

- 地盤振動専用入力の固定順検証
- 既存4変換APIの順次合成
- 非感知、警戒不成立、警戒成立の結果分離
- 感知値、観測、信念候補、警戒意図の中間結果保持
- 同一入力から同一結果を返す正式禊Test
- 専用の因果発生実行と行動候補生成を外側で合成する因果認識閉ループ

未実装:

- 地盤振動信号の移動、反射、遮蔽、寿命更新
- 複数信号と複数観測者の処理
- 信念候補の選択と意図の永続化
- 複数行動候補、候補選択、権能候補、選択結果の因果操作化
- NPCの停止、迂回、退避とゲーム状態反映
