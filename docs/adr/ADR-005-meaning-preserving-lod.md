# ADR-005: 意味保存LODを採用

- Status: Proposed
- Date: 2026-07-10

## Context

世界全体で物理情報伝播、痕跡、知覚、AI、身体、描画を常時詳細計算することはできない。
単純な距離LODでは、遠方の火災、危険、痕跡、因果が消え、詳細領域へ戻った際に世界の意味が途切れる。

## Decision

神髄LODとして、細部を集約しても主要因果、総量、信号方向、危険状態、秩序状態、観測不確実性、将来への影響を保持する意味保存LODを採用する。

高コスト機能には更新頻度、対象数、空間・時間解像度の予算を持たせる。
詳細シミュレーションを現世Sim、遠景シミュレーションを幽世Sim、常駐制御を鎮座Schedulerと呼ぶ候補を採用する。

## Consequences

- LODごとの集約・復元規則と禊Testが必要になる。
- 遠距離でも重要な危険と因果を維持できる。
- 今回は契約や実処理を実装しない。
