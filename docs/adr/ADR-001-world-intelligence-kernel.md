# ADR-001: 思兼神エンジンを世界知能カーネルとして定義

- Status: Accepted
- Date: 2026-07-10

## Context

既存設計は「世界そのものがAIになる」、常態核、偏差、復帰行動、権能Asset、因果Logを中核に置いている。
一方、現行v0.1コードは固定tick、最小状態、左右移動、Event、権能Asset契約までであり、上位構造の正式な境界がなかった。

## Decision

思兼神エンジンを、世界・場所・Asset・Entity・縁が観測と因果を通じて変化する世界知能カーネルとして定義する。
思兼神Coreは固定tick、権威状態、更新順序、因果操作、Event境界を統括する。

基本循環は `世界真実 → 環境・身体・社会状態 → 痕跡と記憶 → 感知値 → 観測 → 信念 → 判断と権能 → 因果操作 → 新しい世界真実` とする。

## Consequences

- AI、描画、物理、Assetを独立した書き換え主体にせず、共通の権威状態と因果経路へ接続する。
- Coreは各詳細アルゴリズムを抱えず、契約と実行順序を管理する。
- 現行v0.1は部分実装として維持し、段階移行する。

## Compatibility

既存Namespace、project名、公開型、Movement/KengouAsset Smokeは変更しない。
