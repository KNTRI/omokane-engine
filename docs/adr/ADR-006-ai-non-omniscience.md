# ADR-006: AIは世界真実を直接参照しない

- Status: Accepted
- Date: 2026-07-10

## Context

AIが世界真実を直接読むと、隠密、誤認、探索、伝聞、知覚差が成立せず、判断理由も不自然になる。
世界そのものがAIになる設計でも、各主体の知識範囲は分離する必要がある。

## Decision

AIの標準認識経路を次に固定する。

```text
World Truth
→ 物理情報伝播
→ 感知値
→ 観測
→ 信念
→ 判断
```

特殊知覚も範囲、精度、誤差、遅延、遮断条件を持つ高性能センサーとして定義する。
NPC、動物、機械、神格へWorld Truthの直接参照を公開しない。

## Consequences

- AI判断には観測生成と信念管理が必要になる。
- 誤認・古い情報・不確実性をゲームルールとして扱える。
- `伝播信号` から観測者固有の `感知値`、`観測`、`信念候補`、一時的な `警戒意図` を作る最小経路を実装する。
- 複数候補の選択、永続的な信念・意図、行動選択、誤差、遅延、遮断条件は後続Phaseとする。

## Implementation Status

実装済み:

- 観測者ID、観測位置、感知設定、伝播信号だけを入力する感知値生成
- 感知値一覧から観測を作る純粋変換
- 明示的な根拠・反証観測から信念候補を作る純粋変換
- 単一の信念候補と明示閾値から一時的な警戒意図を作る純粋変換
- World Truthやゲーム状態を感知値生成へ渡さないAPI境界

未実装:

- 信念候補の採択と永続的な信念状態
- 忘却、時間減衰、反証による既存信念の更新
- 複数信念候補の選択と永続的な意図状態
- ヒステリシス、行動選択、経路変更
- 信念や意図に基づく因果操作生成
- 遮蔽、誤差、遅延、特殊知覚の個別規則
