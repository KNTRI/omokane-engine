# ADR-011: 因果台帳の最小再生は記録結果の検証付き再適用とする

- Status: Accepted
- Date: 2026-07-28

## Context

現在の因果台帳は、成功したEntity位置変更の結果だけを正式履歴として保持する。
入力、AI判断、権能評価、乱数消費を完全に再実行できる情報はまだ保持していない。
また、言霊Eventは通知であり、World Truthそのものではない。

## Decision

Phase 1の因果台帳再生は、記録済み結果を入力順に検証付きで再適用する。

- 対象Entityの現在位置と記録の変更前位置が一致することを事前条件とする。
- 仮状態のTickを記録Tickへ進め、Tick逆行は拒否する。
- Tickの飛びで未記録のEventを合成しない。
- 記録済みEventだけを台帳順・記録内順で再出力する。
- 一件でも失敗した場合は初期状態を返し、途中状態と途中Eventを公開しない。
- 因果操作実行器、入力、AI、権能、乱数を再実行しない。

## Consequences

- 因果台帳が表すEntity位置変更の範囲を決定論的に再構築できる。
- 変更前位置の不一致により、初期状態または台帳の分岐を検出できる。
- 未記録のMovementやTick進行だけの履歴は再現できない。
- 入力列からの完全な記紀Replay、Snapshot、巻き戻しは後続Phaseとなる。
