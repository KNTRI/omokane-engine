# ADR-027: 自発移動制御判断は同一主体・同一Tickの自発移動意図を通過または抑制する

- Status: Accepted
- Date: 2026-08-20

## Context

- 自発移動意図と制御判断が別々に存在しても、接続規則がなければMovementへ安全に渡せない。
- `その場警戒` 中に物理速度を直接ゼロにすべきではない。
- 抑制された意図も説明可能性のため保持する必要がある。
- 複数意図の入力順を決定論的に維持する必要がある。

## Decision

- 意図と判断の実行者IDおよびTick一致を要求する。
- 許可判断では意図を構造的にそのまま通過させる。
- 抑制判断では意図を保持した抑制結果を返す。
- 制御結果をprivate表現とし、不整合な通過・抑制結果を外部構築させない。
- 一括Gateは空一覧を許可し、全件検証後だけ入力順の結果を公開する。
- 一括Gateでは意図ID重複を拒否する。
- 一件でも不正なら部分結果を公開しない。
- 方向の合成、相殺、優先順位付けは行わない。
- Gate結果はWorld Truth、Event、因果操作、正式履歴ではない。

## Consequences

- 自発移動だけを物理外力から独立して止められる。
- 抑制された意図と制御理由を追跡できる。
- Movement Adapterは将来、通過意図だけを扱える。
- 同一主体・同一Tickを越える再評価、持越し、予約は別設計になる。
- 意図裁定、斜め合成、継続、期限は後続となる。

## Implementation Status

実装済み:

- privateな `自発移動意図制御結果`
- 同一主体・同一Tickの単一Gate
- 入力順と原子性を保つ一括Gate
- 意図ID一意性
- 制御判断由来の反応状態、要求ID、成立因果操作IDアクセサ
- 完全因果経路と統合Replay後判断のGate一致

未実装:

- Movement Adapter
- 複数意図の競合裁定、方向合成、優先順位
- 意図予約、期限、持越し、再評価
- Gate結果のEvent化、因果操作化、履歴保存
