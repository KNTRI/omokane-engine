# ADR-028: 通過済み自発移動意図は主体情報を保った互換移動命令へ変換する

- Status: Accepted
- Date: 2026-09-08

## Context

- 意図とGateは存在するが、旧Movementへ接続できる主体付きの互換表現がない。
- 現行Movementはゲーム状態のプレイヤーIDを対象とし、さらにEntity種別がプレイヤーの場合だけ左右入力をX座標へ適用する。
- Inputだけを返すと元の実行者IDが失われ、非プレイヤーの意図がプレイヤーへ誤適用され得る。
- 意図は四方向を表現するが、現行Movementは左右だけを実装している。
- 上流制御による抑制とAdapter能力による方向未対応は異なる。
- 意図を直接物理速度や位置変更へ変換すべきではない。

## Decision

- privateな主体付き `互換移動命令` を導入し、命令種別は左・右だけとする。
- 命令は元のGate結果全体を保持する。実行者ID、Tick、意図ID、方向、由来Inputは重複保存せず既存アクセサへ委譲する。
- privateな `互換移動変換結果` を全域pure関数で生成する。Gateの契約検証を繰り返さず、ResultのErrorを追加しない。
- 最初に通過意図の有無を確認する。抑制なら方向にかかわらず `自発移動抑制` として未生成にする。
- 通過意図の左・右だけを命令生成とし、上・下は明示的な正常理由 `上方向未対応`・`下方向未対応` とする。
- 方向と命令種別は網羅的matchを使う。上下を左右や入力なしへ代替しない。
- 未生成でもGate結果と意図を保持する。
- 一括変換は入力順mapのみとし、再検証、主体/Tick group化、ソート、重複排除を行わない。
- Queryは命令、全未生成、抑制、方向未対応を元の順序で抽出する。
- GameState適用とプレイヤーID検証は後続の適用Adapterへ送る。Input.fsと現行Movementは変更しない。

## Consequences

ADR-029で後段の主体・Tick・Entity・終了状態・現在判断照合を実装した。非空命令は検証済み不変GameStateと一体のprivate準備へ保持する。互換変換自体の全域pure契約は維持し、Movementの実行は依然後続である。

- 意味的意図と旧Movement契約の間に、主体情報を失わない互換境界が成立する。
- 上下未対応を黙ったno-opにせず、制御抑制と区別して説明できる。
- 既存Inputアクセサだけを無条件にMovementへ渡してはならない。次段では命令主体とプレイヤーID、Entity存在・種別、Tickなどの適用契約が必要となる。
- 左右Inputの既存Movement結果等価性をTest内で確認するが、本番AdapterはMovementを呼ばない。
- 上下Movement、任意Entity Movement、位置・速度適用は未実装である。
- World Truthと正式履歴は因果適用された反応状態を保持する。互換値は再導出可能な一時値である。
