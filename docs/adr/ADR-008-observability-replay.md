# ADR-008: 可観測性と再生を初期要件とする

- Status: Accepted
- Date: 2026-07-10

## Context

世界AIの判断は常態、偏差、観測、信念、権能、競合、散逸など複数要因から生じる。
最終結果だけでは、不具合の再現、設計検証、プレイヤーへの説明ができない。

## Decision

言霊Event、因果台帳、神託Debug、記紀Replayを別責務として設計する。

- 言霊Eventは「何が起きたか」を流す。
- 因果台帳は「なぜ起きたか、何に影響したか」を保存する。
- 神託Debugは候補、評価、却下、裁定の理由を開発者へ示す。
- 記紀Replayは同じ初期状態、入力列、Seed、因果順序から再生する。

記録順を安定化し、システム時刻や非安定な列挙順をゲーム結果へ混ぜない。

## Consequences

- 型と処理には原因ID、安定ID、Tick、理由を持たせる必要がある。
- デバッグ情報と世界の正式履歴を同一概念にしない。
- 因果台帳の永続化、完全な記紀Replay、Snapshot、神託Debugは独立した後続実装とする。

## Implementation Status

実装済み:

- 成功したEntity位置変更の記録候補を正式記録へ変換する。
- インメモリのイミュータブル因果台帳へ入力順で原子的に一括追記する。
- 失敗記録を拒否する。
- 現在台帳と追記候補一覧を通じて因果操作IDの重複を拒否する。
- 台帳Tickの非減少順序を保証する。
- Entity位置変更の記録結果を、変更前位置の検証付きで原子的に再適用する。
- 記録済みEvent列を決定論的に再出力する。
- Entity位置変更と地盤振動発生を一つの因果順へ保存する統合因果台帳を提供する。
- 統合Replayで位置変更、Event、記録済み地盤振動信号を原子的に再構築する。

未実装:

- ファイル保存
- セーブデータ統合
- 巻き戻し
- 入力・AI・権能・乱数を再実行する完全な記紀Replay
- Snapshot
- 神託Debug
- 位置変更と地盤振動以外の異種因果結果
- 既存Movementとの統合
