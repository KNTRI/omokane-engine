# ADR-017: 地盤振動発生因果操作はゲーム状態を直接変更せず権威伝播信号を生成する

- Status: Accepted
- Date: 2026-08-09

## Context

`因果操作種別.伝播信号生成` は存在するが、その種別を検証して権威信号を生成する実行器はなかった。
現在の因果操作実行器と因果台帳はEntity位置変更結果に特化しており、地盤振動信号を位置変更として偽装すると、結果再生の意味論が壊れる。
一方、認識経路へ渡す地盤振動信号を呼び出し側が自由に組み立てるだけでは、原因因果IDと発生源の由来を保証できない。

## Decision

- 地盤振動専用の `地盤振動発生操作` と純粋な発生実行器を追加する。
- 因果操作IDを `伝播信号.原因因果ID` へ自動接続する。
- 因果操作の実行者IDを `伝播信号.発生源EntityID` へ自動接続する。
- 量種別と媒体を `地盤振動`、`地盤` へ固定する。
- 発生時はゲーム状態、Tick、Entity、乱数Seed、終了状態を変更しない。
- Eventは因果操作が明示した一覧だけを入力順で返す。
- 複数発生は全件静的検証後に入力順で仮適用し、全成功時だけ信号、記録、Eventを公開する。
- 地盤振動発生記録を、位置変更専用の既存因果台帳へ保存しない。

## Consequences

- 正式な因果操作から認識可能な権威伝播信号を決定論的に生成できる。
- 原因因果ID、発生源EntityID、信号IDの由来を公開契約で追跡できる。
- 位置変更結果再生と信号生成結果再生を混同しない。
- 地盤振動発生記録を正式履歴へ保存する異種因果台帳は後続設計となる。
- 信号寿命の時間発展、媒体上の移動、反射、遮蔽は未実装のままである。

## Implementation Status

実装済み:

- 単一の地盤振動発生操作と固定順検証
- 状態不変の権威伝播信号生成
- 専用の地盤振動発生記録
- 因果操作IDと伝播信号IDの重複を拒否する原子的バッチ

未実装:

- 異種因果台帳への正式保存
- 地盤振動発生記録のReplay
- 信号移動、寿命更新、媒体Field
- 既存Movementとの統合
