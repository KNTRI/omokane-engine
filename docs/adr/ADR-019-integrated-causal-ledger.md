# ADR-019: 異種因果結果は統合因果台帳へ判別共用体として保存する

- Status: Accepted
- Date: 2026-08-09

## Context

既存の `因果台帳` はEntity位置変更結果専用であり、地盤振動発生記録やエンティティ反応状態変更記録は、正式な成功記録であっても保存できなかった。
地盤振動へダミー位置を与える、または位置変更へダミー信号を与えて単一レコードへ押し込むと、記録と再生の意味論が壊れる。
一方、既存の位置変更台帳とReplayには利用中の公開契約と禊Testがあり、即時置換は互換性を損なう。

## Decision

- Entity位置変更記録、地盤振動発生記録、エンティティ反応状態変更記録をprivateな判別共用体 `統合因果記録` で保持する。
- 因果操作ID、Tick、実行者ID、概要、Eventは公開アクセサから取得する。
- 種別固有値はOptionアクセサで取得し、別種へ変換しない。
- 因果操作IDは全記録種別を通じて一意とし、Tickは台帳全体で非減少とする。
- 地盤振動の伝播信号IDも台帳全体で一意とする。
- エンティティ反応要求IDも台帳全体で一意とする。
- 全項目を固定順で検証し、全件成功時だけ入力順で原子的に追記する。
- 既存の `因果台帳` と `因果台帳再生` は位置変更専用の互換APIとして維持する。
- 既存因果台帳から統合因果台帳への一方向移行を提供する。
- ファイル保存、Snapshot、親因果グラフは今回導入しない。

## Consequences

- 異なる種類の成功結果を、一つの安定した正式因果順で保持できる。
- ダミー値を使わず、種類ごとの意味と検証規則を維持できる。
- 既存API互換を保つため、移行期間は位置変更専用台帳と統合台帳が併存する。
- 永続化、Snapshot、親因果グラフ、任意時点Replayは後続となる。

## Implementation Status

実装済み:

- privateな統合因果記録とイミュータブル統合因果台帳
- 種別横断の因果操作ID一意性、Tick非減少、伝播信号ID一意性、反応要求ID一意性
- 入力順を維持する原子的な一括追記
- 三種別の件数・抽出と、因果操作ID・伝播信号ID・反応要求ID検索
- 既存位置変更台帳からの順序保存移行

未実装:

- ファイル保存、セーブデータ統合、Snapshot
- 親因果グラフ、ハッシュチェーン、暗号署名
- 位置変更、地盤振動、エンティティ反応状態変更以外の因果結果
