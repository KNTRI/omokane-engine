# ADR-012: 伝播信号の最小感知変換は明示設定と線形距離減衰を使う

- Status: Accepted
- Date: 2026-07-28

## Context

伝播信号と感知値の契約は存在するが、両者を接続する変換処理がなかった。
AIへWorld TruthやEntity一覧全体を渡さず、観測者固有の情報を作る境界が必要である。
一方、媒体場、遮蔽、反射、遅延を含む完全な伝播シミュレーションは現段階では過剰である。

## Decision

- 入力を現在Tick、観測者ID、観測位置、明示的な感知設定、1件の伝播信号に限定する。
- 量種別・媒体不一致、範囲外、閾値以下は、契約エラーではなく正常な非感知とする。
- 不正な入力または非有限な計算結果だけをエラーとする。
- Phase 1では発生位置との直線距離と線形距離減衰を使う。
- 確信度は感知閾値から確信飽和値までを0.0から1.0へ正規化する。
- 乱数、遮蔽、遅延、誤差、信号寿命の時間発展は使用しない。

## Consequences

- World Truthの権威信号から観測者固有の感知値へ至る最小境界が成立する。
- 地盤振動などの技術垂直スライスから再利用できる。
- この線形モデルは現実の伝播物理を正確に表すものではない。
- 媒体場、移流、拡散、反射、混合、遮蔽、遅延、誤差は後続Phaseとなる。

## Implementation Status

実装済み:

- 明示的な感知設定と固定順の契約検証
- 安定した直線距離計算
- 線形距離減衰、感度倍率、閾値、確信度飽和
- `伝播信号` から `感知値 option` への純粋変換
- 正常な非感知と契約エラーの分離

未実装:

- 信号の移動と寿命更新
- 媒体Field
- 移流、拡散、伝導、波動
- 遮蔽、反射、混合
- センサー誤差、遅延、ノイズ
- 複数信号の合成
- 意味保存LOD
