# ADR-023: その場警戒は物理速度ではなく独立したエンティティ反応状態として保持する

- Status: Accepted
- Date: 2026-08-13

## Context

- エンティティ反応要求は存在するが、World Truth上の反応状態がなかった。
- `その場警戒` を速度ゼロへ直結すると、判断の意味層と物理層が混ざる。
- 空中、落下、押し出しなどでは、警戒中であることと速度ゼロが一致しない。
- 巡路停止や警戒姿勢も、移動、巡路、表現サブシステムの別責務である。

## Decision

- `ゲーム状態` へ `エンティティ反応状態一覧` を追加する。
- 一Entityにつき現在の反応状態は最大一件とする。
- Phase 1の状態種別は `その場警戒` だけとする。
- 反応状態は、成立させた因果操作IDと由来エンティティ反応要求を保持する。
- 反応状態の成立では、位置、速度、HP、巡路を変更しない。
- 現行Movementはまだ反応状態を参照しない。

## Consequences

- 判断結果を、意味を保ったWorld Truthとして正式に反映できる。
- 物理状態と判断由来の反応状態を独立して発展させられる。
- `ゲーム状態` の公開レコードへフィールド追加が発生する。
- 警戒解除、巡路抑制、姿勢、継続時間は後続となる。

## Implementation Status

実装済み:

- privateな `エンティティ反応状態` と由来アクセサ
- 一Entity一反応状態Invariantと実行者ID検索
- GameStateへの反応状態一覧追加
- 同一Entity更新時のlist位置維持
- 既存Movementを変更しない空一覧初期化
- 反応状態を自発移動の許可・抑制へ投影する純粋な読み取り境界
- 自発移動制御判断と同一主体・同一Tickの自発移動意図を接続する純粋Gate

未実装:

- 警戒解除と通常状態への復帰
- Movement Adapter、巡路、姿勢、アニメーションによる状態解釈
- 複数反応状態、継続時間、ヒステリシス
