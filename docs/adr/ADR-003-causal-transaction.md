# ADR-003: 永続的な世界変更を因果操作経由とする

- Status: Proposed
- Date: 2026-07-10

## Context

AI、物理、権能、環境、個別スクリプトが権威状態を直接変更すると、競合解決、説明、再生、決定論を統一できない。
現行 `思兼神.更新する` はプレイヤー位置とTickを直接更新しており、将来方針と差分がある。

## Decision

永続的な世界変更は、因果操作または同等のWorldTransactionを経由する。
因果操作はID、Tick、種別、原因、実行者、対象、概要、発行予定Eventを持つ最小契約から始める。

入力、AI判断、環境反応、権能操作は因果操作を生成し、検証・予約・裁定・担当サブシステム処理・状態反映へ進む。

## Existing Conflict

現行 `思兼神.更新する` の直接更新は、v0.1の通電確認として限定的に許容する。
今回リファクタリングせず、将来 `入力意図 → 因果操作 → 天鳥船Motion → 状態反映` へ移行する。

現行 `権能Asset.発行Event一覧` も維持し、将来 `権能Asset → 神威Operation → 因果操作 → Event / Trace / 因果台帳` へ拡張する。

## Consequences

- 書き換え経路と説明可能性を統一できる。
- 実行器、競合裁定、台帳が必要になる。
- 契約型の追加だけではTransaction化完了とはみなさない。

## Implementation Status

部分実装済み:

- Entity位置変更の単体実行と原子的な操作列適用
- `因果操作種別.伝播信号生成` による状態不変の地盤振動信号生成と原子的バッチ
- 因果IDと実行者IDから生成信号への由来接続
- Entity位置変更と地盤振動発生を混在保存・結果再生する統合因果台帳
- 選択済み行動候補から状態不変の意味的な `エンティティ反応要求` を作る因果操作前段

未実装:

- 現行 `思兼神.更新する` のMovement経路を含む、全永続変更のTransaction化
- 汎用異種操作列、結界Lock、天津裁定
- エンティティ反応要求の権威状態への写像、因果操作化、実行
- 統合因果台帳の永続化と完全な記紀Replay

このためStatusは `Proposed` のまま維持する。
