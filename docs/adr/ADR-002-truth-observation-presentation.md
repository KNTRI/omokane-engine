# ADR-002: 世界真実・観測・表現を分離

- Status: Proposed
- Date: 2026-07-10

## Context

世界AIでは、世界で成立している事実、主体が知っていること、プレイヤーに見えるものが異なる。
これらを同一データにすると、AIの全知化、描画品質によるゲーム結果の変化、誤った保存が起きる。

## Decision

次の三面を別契約として扱う。

- 世界真実: 保存・再現可能な権威状態。
- 観測: センサー経由で得た不完全、時点付き、確信度付きの情報。
- 表現: 描画、音、UIのための派生データ。

AIは観測と信念を読み、表現層は世界真実またはEventから表示状態を生成する。
観測と表現から世界真実を直接上書きしない。

## Consequences

- 同じ現象に権威型、観測型、表示型が存在し得る。
- データ量は増えるが、セーブ、AI、Renderer、デバッグの責務が明確になる。
- 現行 `ゲーム状態` は世界真実の最小候補だが、境界はまだ実装されていない。
