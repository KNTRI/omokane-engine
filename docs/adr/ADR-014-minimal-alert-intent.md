# ADR-014: 信念候補からの最小警戒意図生成は単一の明示閾値を使う

- Status: Accepted
- Date: 2026-08-01

## Context

信念候補まで生成できるが、判断層の意図へ接続する境界がなかった。
`信念候補` 型には観測者IDが直接保存されておらず、根拠・反証観測から主体を追跡する必要がある。
複数候補の比較、Utility AI、行動選択、警戒段階は現段階では過剰である。

## Decision

- 1件の信念候補を1件の明示的な発生閾値と比較する。
- 候補確率が閾値未満なら正常な意図不成立とする。
- 候補確率が閾値以上なら警戒意図を生成する。
- 観測者IDは根拠一覧、反証一覧の順で連結した先頭観測から導出する。
- 警戒度は候補確率を再計算せず、そのまま保持する。
- 由来信念候補を説明可能性のため構造的に保存する。
- 行動、警戒段階、意図の永続化はまだ決めない。

## Consequences

- 信念候補から判断層へ至る最小境界が成立する。
- 伝播信号から警戒意図まで、ゲーム状態を渡さない標準認識経路を接続できる。
- 地盤振動の技術垂直スライスへ再利用できる。
- 候補選択、ヒステリシス、段階分類、行動選択は後続Phaseとなる。

## Implementation Status

実装済み:

- 単一の発生閾値と固定順の契約検証
- 信念候補、根拠・反証観測、観測者境界の防御的検証
- 候補確率による決定論的な成立・不成立判定
- 観測者ID、対象仮説、警戒度、由来候補を持つ一時的な警戒意図

未実装:

- 複数信念候補の選択
- 永続的な意図状態とヒステリシス
- 警戒段階と複数閾値
- 行動選択、経路変更、退避、攻撃
- 意図に基づく権能候補または因果操作の生成
