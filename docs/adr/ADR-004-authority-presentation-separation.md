# ADR-004: 権威層と表現層を分離

- Status: Accepted
- Date: 2026-07-10

## Context

既存設計はCoreとRendererを分離し、Coreが描画を直接行わない方針を採用している。
世界知能カーネルでは、煙、痕跡、身体変形、音響などにも同じ境界が必要になる。

## Decision

権威層はCPU中心、保存可能、再現可能とし、ゲームルールとAIが参照する。
表現層はGPU中心でもよく、一時的、高解像度、非決定的でもよい。

GPU煙、粒子、デカール、音響エフェクトを権威状態の唯一の保存先またはAI入力にしない。
天照Rendererと八咫鏡Viewは読み取り専用の表示状態を受け取る。

## Consequences

- 画質設定や描画負荷がゲーム結果を変えない。
- 表現を再生成できる権威データが必要になる。
- 局所演出は世界真実へ昇格させずに済む。
