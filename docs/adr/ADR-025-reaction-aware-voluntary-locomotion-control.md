# ADR-025: その場警戒状態は物理速度ではなく自発移動制御判断へ投影する

- Status: Accepted
- Date: 2026-08-20

## Context

- World Truth上に `その場警戒` のエンティティ反応状態は存在するが、Movementが読むための境界がなかった。
- 警戒状態を速度ゼロへ直結すると、主体が開始する自発移動と、重力、落下、慣性、ノックバック、押し出しなどの外力移動が混ざる。
- 現行 `思兼神.更新する` はプレイヤー入力を直接位置へ適用する互換経路であり、反応状態を参照しない。
- Persistent Causal Worldの方針では、権威状態と下流の表現・実行を独立した明示ルールで接続する必要がある。

## Decision

- 反応状態からprivateな `自発移動制御判断` を導出する。
- 対象Entityに反応状態がなければ、自発移動を許可する。
- 対象Entityが `その場警戒` 中なら、自発移動を抑制する。
- 位置、速度、HP、当たり判定、所有者を判断材料にせず、変更もしない。
- 判断の評価Tickには現在のゲーム状態Tickを使い、反応状態の成立Tickとは区別する。
- 対象反応状態の成立Tickが現在のゲーム状態Tickより後なら契約不整合として拒否する。
- 終了状態によるゲーム全体の停止は上位実行順序の責務とし、この判断の抑制理由やErrorへ混ぜない。
- 判断はWorld Truthから導出される一時的なread modelであり、World Truth、Event、因果操作、因果記録ではない。
- 自発移動意図と意図gateは独立境界とし、現行Movementへの実接続はさらに後続とする。

## Consequences

- `その場警戒` と物理運動を分離したまま、将来のMovement Adapterへ接続できる。
- 自発移動だけを抑制対象とするため、外力、落下、押し出し、移動床による運動を維持できる。
- live適用後と統合Replay後の同一World Truthから、構造的に同一の判断を再生成できる。
- 同じ制御判断を、同一主体・同一Tickの自発移動意図を通過または抑制するpure Gateへ渡せる。
- 現行Movementはまだ判断を読まず、プレイヤー入力やEntity位置の更新契約も変わらない。
- Movement Adapter、意図競合裁定、反応状態解除は後続設計となる。

## Implementation Status

実装済み:

- privateな `自発移動制御判断`
- 反応状態なしからの許可判断
- `その場警戒` 状態からの抑制判断
- 固定順のEntity・状態一覧・Tick検証
- 成立因果操作、要求、候補、仮説、優先度を辿るProvenanceアクセサ
- 完全因果経路と統合Replay後状態からの同一判断生成
- privateな自発移動意図と、明示方向・既存Inputからの意図生成
- 同一主体・同一Tickを検証する単一・一括の自発移動意図gate

未実装:

- 互換命令のMovement適用Adapterへの接続（Gate後の主体付き互換変換はADR-028で実装済み）
- 物理速度、位置、巡路への適用
- 反応状態の解除、期限、ヒステリシス
