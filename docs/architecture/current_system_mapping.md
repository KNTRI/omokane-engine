# 現行システム対応表

## 1. 目的

世界知能カーネルの新概念を、現在のv0.1コードと設計へ対応付ける。
`Existing`、`Partial`、`Missing`、`Deferred`、`Conflict` を使い、存在しない実装をあるものとして扱わない。

## 3. 現行直接更新の扱い

現在の `思兼神.更新する` は、入力一覧を現在状態へ直接適用し、プレイヤーのX座標とTickを更新している。
世界知能カーネルの最終経路とは異なるが、v0.1の通電確認として許容する。

今回リファクタリングせず、Movement Smokeも変更しない。
将来的には次へ移行する。

```text
入力意図
→ 因果操作
→ 天鳥船Motion
→ 世界状態反映
→ 言霊Event / 因果台帳
```

この差分は [ADR-003](../adr/ADR-003-causal-transaction.md) に記録する。

## 4. 権能Asset公開契約の扱い

現在の `権能Asset.発行Event一覧` はv0.1互換として維持し、今回変更しない。
将来的には次へ移行する。

```text
権能Asset
→ 神威Operation
→ 因果操作
→ Event / Trace / 因果台帳
```

移行時も既存Assetを黙って読み替えず、版管理または変換境界を設ける。

## 5. 今回の非目標

契約型の追加は、実行基盤の完成を意味しない。
因果操作実行、伝播計算、AI判断、因果台帳、地表記憶、身体システム、LOD、常駐制御は今後の独立作業とする。
