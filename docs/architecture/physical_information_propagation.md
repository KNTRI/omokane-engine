# 物理情報伝播層

## 1. 目的

風土Propagationは、世界真実にある現象が媒体を通り、主体の感知値へ届くまでを扱う物理情報伝播層である。
AIの非全知性、痕跡、環境反応、知覚差、説明可能性を同じ因果経路へ接続する。

## 2. 基本経路

```text
Source
→ Emission
→ Carrier / Medium
→ Propagation
→ Attenuation / Diffusion / Reflection / Mixing
→ 感知値
→ 観測
→ 信念
→ 判断
```

- Sourceは、火、Entity、地表痕跡、権能操作などの発生源である。
- Emissionは、何を、どの強度・方向・期間で放出したかを表す。
- Carrier / Mediumは、信号を運ぶ大気、水、土壌、物体、生体、霊場などである。
- Propagationは、媒体上で信号を移動・変形させる規則である。
- 感知値以降は、世界真実ではなく主体ごとの認識経路になる。

## 4. 権威信号と表現信号

伝播信号は、ゲームルールとAIが参照する権威情報である。
煙粒子、音響エフェクト、光のポストエフェクトは、伝播信号を表現する派生データである。

```text
権威信号
  ├─ 感知値と観測へ変換
  └─ 表現層の粒子・音・光へ変換
```

表現結果から権威信号を逆算しない。
画質設定やGPU負荷によってAI判断が変わらないようにする。

## 5. 感知値への変換

感知値は、観測者、信号、感知種別、測定値、確信度、Tickを持つ最小契約とする。
`感知設定` は対象量、媒体、最大距離、感度倍率、感知閾値、確信飽和値を明示する。
`感知値生成.伝播信号から作る` は、観測者の位置と信号の発生位置の直線距離に線形減衰を適用し、観測者固有の感知値を作る。

```text
距離係数 = max 0.0 (1.0 - 距離 / 最大距離)
測定値 = 信号強度 × 感度倍率 × 距離係数
```

量種別・媒体不一致、最大距離以上、閾値以下は正常な非感知であり、入力不正とは区別する。
遮蔽、誤差、遅延、反射、混合はまだ扱わない。

特殊知覚も同じ経路を使う。
神格の権能感知は高性能であってよいが、無制限のWorld Truth直読にはしない。

### 地盤振動の技術垂直スライス

`地盤振動警戒経路.実行する` は、すでに権威層で成立している1件の地盤振動信号を開始点として、既存の感知値・観測・信念候補・警戒意図生成を順次合成する。
地盤振動専用の量種別と媒体の不一致は配線契約エラーとし、距離範囲外や感知閾値以下は正常な非感知として区別する。
信号の発生や移動は行わず、警戒意図から行動または世界状態を生成しない。

## 6. 決定論

権威層の伝播計算は、同じ初期状態、同じ入力列、同じSeed、同じ更新順なら同じ信号と感知値を返す必要がある。
次に依存しない。

- GPU粒子数
- フレームレート
- システム時刻
- 非安定なコレクション列挙順
- 並列処理の完了順

## 7. 意味保存LOD

高解像度のセルや個々の粒子を遠距離で省略しても、次を保持する。

- 信号の総量と主要な発生源
- 主な進行方向
- 危険閾値の超過
- 観測可能性と不確実性
- 将来tickで詳細領域へ戻したときの継続性

## 8. 今回の実装境界

実装済み:

- `伝播信号` の契約と有限値検証
- 明示的な `感知設定`
- 発生位置との直線距離と線形距離減衰
- 感度倍率、感知閾値、確信度飽和
- `伝播信号` から `感知値 option` への純粋変換
- 地盤振動信号から警戒意図までのゲーム状態非依存な専用経路
- 非感知、警戒不成立、警戒成立の区別と中間結果保持

未実装:

- 信号自体の移動と寿命の時間発展
- 移流、拡散、伝導、波動の計算
- 媒体Field、遮蔽、反射、混合
- センサー誤差、遅延、ノイズ
- 複数信号の合成
- 複数観測者の一括処理と警戒意図からの行動生成
- 意味保存LOD
