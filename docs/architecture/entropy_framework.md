# エントロピー基盤

## 1. 目的

黄泉Entropyは、世界に継続的に生じる散逸、拡散、劣化、風化、不確実性、維持負荷を表す基盤である。
単一の「世界エントロピー値」であらゆる劣化を代用せず、意味と単位の異なる散逸を分離する。

## 2. 散逸種別

| 種別 | 意味 | 代表例 |
|---|---|---|
| 熱散逸 | 温度差や利用可能な熱が失われる | 焚き火が冷える、熱源から遠ざかる |
| 物質拡散 | 物質が広がり濃度差が減る | 煙、匂い、汚染、水分 |
| 構造劣化 | 物体や施設の機能・強度が失われる | 腐食、疲労、破損 |
| 痕跡風化 | 地表痕跡や権能残滓の判読性が下がる | 足跡、焦げ、匂い、残滓 |
| 情報不確実性 | 観測や信念の確からしさが時間・距離で下がる | 古い目撃情報、伝聞 |
| 常態維持負荷 | 秩序・機能を保つために必要な継続コスト | 結界維持、清掃、修繕、警備 |

これらを足し合わせた万能値をCoreへ導入しない。
必要な関係は、因果操作、状態場、常態核、偏差、個別規則で明示する。

## 3. 禍津・黄泉・直毘の分担

### 禍津

事故、災害、異常など、離散的に起きるEventである。
火災発生、堤防決壊、権能暴走などを開始点として表す。

### 黄泉Entropy

Event後を含めて継続する散逸、風化、不可逆変化である。
時間経過に伴う熱散逸、汚染拡散、構造劣化などを扱う。

### 直毘Homeostasis

秩序維持、修復、常態維持の働きである。
散逸を無効化する万能回復ではなく、資源、権限、範囲、時間、代償を持つ因果操作として扱う。

```text
禍津Eventが偏差を生む
  ↓
黄泉Entropyが散逸・劣化を進める
  ↓
直毘Homeostasisが資源を使って秩序を回復する
```

## 4. 権威状態と派生値

散逸状態は、ゲームルール上保存すべき意味がある場合だけ世界真実へ置く。
視覚的な汚れ量など単一用途の値は表現層の派生データを優先する。

永続状態として追加する場合は、ゲームプレイ、AI、描画、音響、物理、物語、社会シミュレーションのうち三系統以上の利用を目安とする。

## 5. 因果操作との関係

散逸の進行と回復は、永続変更であるため因果操作へ接続する。

```text
散逸規則または禍津Event
→ 因果操作
→ 散逸状態・状態場・痕跡の変更
→ 言霊Event
→ 因果台帳
```

権能による浄化、修復、封印も同じ経路を使い、黄泉Entropyを直接消去しない。

## 6. 意味保存LOD

遠距離では個別のひび、粒子、温度セルを集約できる。
ただし、次を保持する。

- 劣化・散逸の総量
- 主要な発生源と原因因果
- 危険状態と閾値超過
- 回復に必要な負荷
- 痕跡の判読可能性
- 詳細シミュレーションへ戻すための継続状態

## 7. 決定論と検証

散逸の更新順、丸め、同点処理、集約・復元規則を固定する。
数値はNaN、Infinity、負値などの不正状態を契約検証で拒否する。

## 8. 今回の実装境界

今回追加する `散逸状態` は、散逸種別と非負有限値を持つ最小契約である。
散逸率、時間発展、相互変換、直毘Operation、保存形式は実装しない。
