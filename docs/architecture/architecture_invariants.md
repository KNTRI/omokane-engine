# アーキテクチャ不変条件

この文書は、世界知能カーネルへ機能を追加するときに破ってはならない神律Invariantを定義する。
既存v0.1との一時的な差分は、個別ADRと現行システム対応表に明示する。

## INV-01 世界真実・観測・表現を分離する

- 世界真実は、世界で実際に成立している権威状態である。
- 観測は、Entityがセンサーを通して得た不完全な情報である。
- 表現は、プレイヤーへ見せる描画、音、UIである。
- 三つを同一データとして扱わない。

## INV-02 AIは世界真実を直接読まない

AIは原則として `World Truth → 物理情報伝播 → 感知値 → 観測 → 信念 → 判断` の経路だけで世界を知る。
NPC、動物、機械、神格に世界真実の直接参照を与えない。
特殊知覚も範囲、誤差、遅延、遮断条件を持つセンサーとして定義する。

## INV-03 永続変更は因果操作経由とする

世界へ永続的な変更を加える場合、因果操作または同等のTransactionを経由する。
描画、AI、物理、音響、個別スクリプトが独立に権威状態を書き換えない。

現行v0.1の `思兼神.更新する` による直接更新は、移行前の限定的な例外である。

## INV-04 描画結果を世界真実にしない

次を禁止する。

- GPU煙をAIが直接読む。
- デカールを足跡の唯一の保存先にする。
- 画質設定を下げるとAI判断が変わる。
- GPU粒子をセーブデータの権威状態にする。

## INV-05 権威層と表現層を分離する

権威層はCPU中心、保存可能、再現可能で、ゲームルールとAIの入力になる。
表現層はGPU中心でもよく、一時的、高解像度、非決定的でもよい。
表現層は権威層を読み取れるが、権威状態の唯一の書き手にはならない。

## INV-06 高コスト機能にはLODと予算を持たせる

物理情報伝播、環境反応、痕跡、知覚、AI推論、身体変形、描画、音響には、更新頻度、対象数、空間解像度、時間解像度などの予算を定義する。

## INV-07 LODは意味を保存する

遠距離で細部を捨てても、主要因果、総量、信号方向、危険状態、秩序状態、観測不確実性、将来への影響を保持する。

## INV-08 権能も通常の因果基盤を使う

権能だけが物理、伝播、散逸、因果、知覚を迂回してはならない。
権能は権限、範囲、優先度、持続時間、代償、競合規則、観測可能性、残滓、解除条件を持つ設計へ段階的に拡張する。

## INV-09 重要結果は説明・再現できる

同じ初期状態、同じ入力列、同じSeedなら、同じ言霊Event列と因果Logを返す。
重要な判断には、因果Log、神託Debug、安定した順序、タイブレーク規則を用意する。

## INV-10 性能低下時も重要情報を守る

装飾より、攻撃予兆、敵意図、危険範囲、移動可能性、重要な痕跡、知覚に必要な信号を優先する。

## INV-11 新しい永続状態には複数利用者を要求する

新しい永続的な世界状態は、ゲームプレイ、AI、描画、音響、物理、物語、社会シミュレーションのうち、原則として三系統以上から使われることを目安とする。
単一用途なら、世界状態ではなく局所演出または派生データを検討する。

## INV-12 衝突はADRへ残す

新設計と既存コード・既存仕様が衝突する場合、黙って上書きしない。
互換期間、例外、移行条件、却下した案を神議ADRへ記録する。

## 変更時チェック

新規機能は最低限、次を設計レビューで答える。

1. World Truth、Observation、Presentationのどこに属するか。
2. 永続変更はどの因果操作を通るか。
3. AIが読む観測はどの伝播信号と感知値から作るか。
4. 保存、再現、LOD、性能予算、神託Debugをどう扱うか。
5. 既存仕様との衝突をどのADRへ残したか。
