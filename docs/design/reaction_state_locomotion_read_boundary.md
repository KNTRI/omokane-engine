# エンティティ反応状態から自発移動制御判断を導出する最小読み取り境界

## 1. 目的

World Truthに成立した `エンティティ反応状態` を読み、対象Entityの自発移動を許可または抑制する一時的な判断値へ投影する。
この境界はMovementを実行せず、Entityやゲーム状態を変更しない。

## 2. World Truthと派生判断

`エンティティ反応状態` は因果操作を経てGameStateへ成立したWorld Truthである。
`自発移動制御判断` は現在のGameStateから純粋に導出されるread modelであり、保存対象のWorld Truthではない。

## 3. 自発移動の定義

自発移動は、主体自身の判断、入力、将来のlocomotion意図によって開始される移動を指す。
重力、落下、慣性、ノックバック、押し出し、移動床、外部因果による位置変更は含まない。

## 4. 外力との分離

`その場警戒` を速度ゼロや位置固定へ変換しない。
抑制判断は将来の自発移動意図を下流へ通さないための情報であり、既に存在する物理運動や外力を消去する命令ではない。

## 5. 許可と抑制

```text
対象Entityに反応状態なし
→ 自発移動制御種別.許可
→ 自発移動制御理由.反応状態なし

対象Entityがその場警戒中
→ 自発移動制御種別.抑制
→ 自発移動制御理由.その場警戒中
```

反応種別は網羅的な判別共用体matchで処理する。将来caseを追加したとき、暗黙に抑制へ落とさない。

## 6. 反応状態なし

反応状態がないことはErrorではない。
反応状態を理由とする抑制が存在しないため、正常な許可判断を返す。

## 7. その場警戒中

対象Entity自身の `その場警戒` 状態だけが抑制理由になる。
他Entityの状態、状態一覧の順序、全体の最大優先度は対象の判断へ影響しない。

## 8. 評価Tickと成立Tick

判断の評価Tickは `ゲーム状態.Tick`、由来成立Tickは反応状態を成立させた要求Tickである。

```text
反応状態成立Tick = 10
現在ゲーム状態Tick = 25
判断.評価Tick = 25
判断.由来成立Tick = Some 10
```

対象状態の成立Tickが現在Tickより後なら、未来のWorld Truthを読んだ不整合として拒否する。

## 9. Entity適格性

プレイヤー、敵、弾、障害物のすべてを型上許可する。
Entity種別、所有者、HP、当たり判定からNPCやlocomotion能力を推測しない。
実際に自発移動意図を持つEntityかどうかは将来のMovement Adapterの責務とする。

## 10. 終了状態の責務外

ゲームオーバーやクリアでも、現在のWorld Truthを読み取ることはできる。
終了状態による全入力・更新停止は上位のtick実行順序が扱い、このread modelの抑制理由やErrorにはしない。

## 11. Provenance

抑制判断は保存した反応状態をそのまま保持し、既存アクセサへ委譲して次を辿れる。

- 成立因果操作ID
- 成立Tick
- 由来反応要求ID
- 由来行動候補ID
- 対象仮説
- 優先度

由来値を再計算、正規化、再選択しない。

## 12. GameState読み取り

`自発移動制御判断生成.ゲーム状態から作る` は対象EntityIDとGameStateだけを受け取る。
対象Entity存在・一意性、一Entity一反応状態Invariant、未来成立Tickを固定順で検証する。
GameState、Entity一覧、反応状態一覧、Tick、Seed、終了状態を変更しない。

## 13. Input境界

`入力` を受け取らず、filterや `入力なし` への変換を行わない。
`Input.fs` の既存契約は変更しない。

## 14. Movement境界

現行 `思兼神.更新する` はこの判断をまだ参照しない。
プレイヤー位置更新、Tick進行、Movement Eventは従来どおりであり、今回の読み取り境界とは意図的に未接続である。

## 15. Event・因果・履歴境界

判断生成はEvent、因果操作、更新結果、因果記録を返さず、統合因果台帳へ追記しない。
判断そのものをReplayするのではなく、ReplayされたWorld Truthから同じ判断を再生成する。

## 16. 完全因果経路との接続

```text
地盤振動発生因果
→ 統合因果台帳
→ 正式信号Replay
→ 感知
→ 観測
→ 信念候補
→ 警戒意図
→ 行動候補
→ 選択済み行動候補
→ エンティティ反応要求
→ 反応状態変更因果操作
→ エンティティ反応状態
→ 自発移動制御判断.抑制
```

認識段階のWorld Truth直読を追加せず、正式な由来鎖を判断まで保持する。

## 17. 統合Replayとの接続

反応状態変更記録を含む統合台帳を初期状態からReplayし、再構築されたGameStateを判断APIへ渡す。
同じWorld Truthについてlive判断とReplay判断は構造的に一致する。
判断生成はReplayのEvent、信号、台帳を変更しない。

## 18. Persistent Causal Worldとの関係

権威状態は因果操作と正式履歴を通して成立・再現し、下流機能はその状態を明示的な純粋境界で読む。
今回の実装は、反応状態を直接Movementへ埋め込まず、再生可能なWorld Truthと一時的な制御判断を分離する。

## 19. 決定論

現在時刻、GUID、乱数、外部環境、並列完了順、DictionaryやHashSetの列挙順に依存しない。
対象IDと構造的に同一のGameStateから、構造的に同一の判断または固定順Errorを返す。

## 20. 自発移動意図gateへの接続

privateな自発移動意図と制御結果を追加し、同一主体・同一Tickの判断で意図を通過または抑制する境界を実装した。
抑制結果は意図を破棄せず、外力、落下、押し出しを停止対象へ含めない。
