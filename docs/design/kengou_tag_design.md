# 権能タグ設計

## 1. 概要

権能タグは、権能Assetを分類・検索・デバッグ・UI表示・将来的なAI判断に使うための分類情報である。

権能タグは、権能名そのものではなく、複数の権能に共通して使える性質だけを表す。

1つの権能は複数のタグを持つ。

```fsharp
タグ: Set<権能タグ>
```

`Set<権能タグ>` を使う理由は、タグ重複を避けるためである。

## 2. 基本方針

```text
- 権能タグは、権能名そのものではなく分類性質を表す
- 1つの権能は複数タグを持つ
- タグは Set<権能タグ> で持つ
- 最初は分類、デバッグ、UI表示に使う
- AI制御への本格利用は、権能候補が増えてからでよい
- 分類軸は1軸ではなく、複数軸で扱う
```

権能タグは「攻撃する」「食べる」のような権能名をそのまま写すものではない。
複数の権能を横断して扱える分類棚として使う。

悪い例:

```text
- 攻撃するタグ
- 食べるタグ
- 暖まるタグ
```

良い例:

```text
- 攻撃系
- 食事系
- 使用者を更新する
- 対象を削除する
- 焚き火対象
- 敵対行動
- AI選択可能
```

## 3. 採用する分類軸

以下の5軸を採用する。

```text
1. 目的タグ
   その権能が何のための行動かを表す。

2. 世界への作用タグ
   その権能がEntityや世界に何を起こすかを表す。

3. 対象タグ
   どの種類の対象に向けた権能かを表す。

4. 関係性タグ
   敵対的か、友好的か、中立か、自己対象かを表す。

5. 運用タグ
   AI・プレイヤー・デバッグ・使用回数など、運用上の扱いを表す。
```

分類軸を分けることで、「攻撃系かつ敵対行動かつAI選択可能」のように、権能を複数の観点から絞り込める。

## 5. 権能型との関係

将来的に、権能型には以下のように `タグ` を持たせる予定である。
ただし、これは設計イメージであり、今回の作業では実装しない。

```fsharp
and 権能 =
    {
        名前: string
        タグ: Set<権能タグ>
        使用条件: 依代Entity -> 依代Entity -> bool
        評価: 依代Entity -> 依代Entity -> int
        実行: 世界 -> 依代Entity -> 依代Entity -> 権能結果
    }
```

権能タグは、権能が持つ能力そのものではない。
実際に何をするかは `実行`、使えるかどうかは `使用条件`、選ぶ価値は `評価` が担当する。

## 7. 補助関数候補

将来的な補助関数候補として、以下を想定する。
今回の作業では実装しない。

```fsharp
let タグを持つか (タグ: 権能タグ) (権能: 権能) : bool =
    権能.タグ |> Set.contains タグ
```

使用例:

```fsharp
let 敵対候補 =
    候補一覧
    |> List.filter (fun 候補 ->
        候補.権能 |> タグを持つか 敵対行動
    )

let プレイヤー表示候補 =
    候補一覧
    |> List.filter (fun 候補 ->
        候補.権能 |> タグを持つか プレイヤー選択可能
    )
```

## 8. 設計上の注意

```text
- タグを増やしすぎない
- タグは分類棚であって、すべての判断をタグだけで行わない
- 最初は「見える化」「デバッグ」「UI分類」に使う
- AI判断への利用は、戦闘中・非戦闘中・恐怖状態・空腹状態などが増えてからでよい
- 権能タグ以外にも、将来的には Entityタグ / 状態タグ / 世界タグ が必要になる可能性が高い
```

タグは便利だが、ゲームルールの中心そのものではない。
タグだけで処理を決めると、権能の文脈や対象の状態を見落としやすい。

## 9. AI判断との距離

現時点では、権能タグはAI判断の主軸にしない。

```text
初期段階:
  タグは分類、検索、デバッグ、UI表示に使う。

将来:
  AIが候補権能を絞り込む補助情報として使う。

禁止:
  AI判断のすべてをタグだけで行う。
```

AI判断では、将来的に以下も必要になる可能性がある。

```text
- 現在状態
- 欲求
- 常態核
- 偏差
- 距離
- 危険度
- 対象との縁
- 世界状態
- 使用条件
- 評価関数
```

権能タグは、AIが見る情報のひとつにすぎない。
常態収束機、使用条件、評価関数、世界状態と組み合わせて初めて、判断材料として意味を持つ。
